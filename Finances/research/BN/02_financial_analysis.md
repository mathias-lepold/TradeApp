## Bewertungsrahmen: GAAP vs. Distributable Earnings vs. Plan Value

Brookfield sollte NICHT primär nach GAAP-Gewinn bewertet werden:

| Bewertungsansatz | Wert | Implikation |
|---|---|---|
| GAAP P/E (TTM) | ~87× | Irreführend hoch durch Mark-to-Market-Schwankungen |
| Kurs / DE vor Realisierungen | ~20× ($45,98 / $2,27) | Moderates Niveau für einen wachsenden Asset Manager |
| Kurs / DE inkl. Realisierungen | ~18× ($45,98 / $2,54) | Attraktiv im Peer-Vergleich |
| Kurs / Plan Value | ~68 % ($45,98 / $68) | ~33 % Abschlag auf NAV-Methodik |
| P/B (buchwertbasiert) | ~2,1× | Für Asset Manager moderat |

**Kernaussage:** Der Plan Value von $68/Aktie (Ende 2025), der auf Basis langfristiger Cashflows und NAV-Komponenten berechnet wird, ist die relevanteste Bewertungsgröße. Der aktuelle 33 %-Discount ist historisch groß und bietet attraktiven Einstiegspuffer – vorausgesetzt, der Plan Value wächst planmäßig weiter.
