# 04 – Valuation Model: Brookfield Corporation (BN)

> **Analysedatum:** 2026-05-31 · **Kurs:** $45,98 (31.05.2026)
> ⚠️ Keine Anlageberatung. Nur zur Information. Alle Schätzungen sind Modellwerte, keine Garantien.

---

## Bewertungsmethodik-Überblick

Brookfield Corporation ist aufgrund seiner Holdingstruktur mit drei sehr unterschiedlichen Segmenten (Asset Manager, Versicherung, Operating Businesses) nicht sinnvoll mit einem einzelnen Multiplikator zu bewerten. Es kommen drei Hauptansätze zum Einsatz:

1. **Plan Value / NAV-Methode** (Managementangabe, primär)
2. **Sum-of-the-Parts (SOTP)** – Segmentbewertung
3. **Distributable-Earnings-Multiplikator** (vergleichbar mit Peer-Gruppe)

---

## Methode 1: Plan Value / NAV

Brookfields eigene Bewertungsmetrik – berechnet auf Basis der Barwerte langfristiger Cashflows der Beteiligungen:

| Parameter | Wert | Quelle |
|---|---|---|
| Plan Value Ende 2025 | ~$68 / Aktie | Brookfield IR (Motley Fool, IndexBox, 2026) |
| Historisches Wachstum (5J) | ~16 % p.a. ($32 → $67) | IndexBox / Motley Fool |
| Zielpfad 2030 | $140 / Aktie (>15 % p.a.) | Brookfield Guidance |
| Aktueller Kurs | $45,98 | Markt, 31.05.2026 |
| Discount auf Plan Value | ~33 % | Berechnung: ($68 – $45,98) / $68 |

**Fazit Methode 1:** Bei historisch 16 % PV-Wachstum und einem fairen Kurs bei ~90–100 % des Plan Values ergibt sich ein Fair Value von $61–$75 (leichter Abschlag auf Plan Value für Holdingdiscount akzeptiert).

---

## Methode 2: Sum-of-the-Parts (SOTP)

### Segment Asset Management (BAM-Beteiligung ~75 %)

- BAM FRE (LTM): $3,1 Mrd.
- Marktkapitalisierung BAM (100 %): ~$95–100 Mrd. (impliziertes ~30× FRE-Multiple, typisch für führende Alt-Asset-Manager)
- BN-Anteil (75 %): ~$71–75 Mrd.
- Auf BN-Aktien (ca. 2,38 Mrd. ausstehend): **~$30–31 je Aktie allein für BAM-Stake**

### Segment Wealth Solutions (BNT, Versicherung)

- Book Equity: $13,2 Mrd.
- RoE ~15 %, rechtfertigt ~1,5–2× P/B
- Implied Value: ~$20–26 Mrd. (Gesamtbeteiligung BN ~100 % nach Fusion)
- Je BN-Aktie: **~$8–11**

### Operating Businesses (Infra, RE, Erneuerbare, PE)

- DE aus Op. Businesses Q1 2026: $360 Mio. (annualisiert ~$1,4 Mrd.)
- Diskontiert mit 10–12 %, möglicher Carrying Value + Marktbewertungen
- Deployable Capital: $188 Mrd. insgesamt (Großteil in Fonds, nicht Eigenkapital)
- Angenommener NAV Operating Businesses: $15–25 Mrd.
- Je BN-Aktie: **~$6–11**

### SOTP-Zusammenfassung

| Segment | Wert je BN-Aktie (Bear) | Wert je BN-Aktie (Bull) |
|---|---|---|
| BAM-Beteiligung (75 %) | $28 | $34 |
| Wealth Solutions (BNT) | $8 | $11 |
| Operating Businesses | $6 | $11 |
| Nettoverschuldung / Corp. Overhead | −$4 | −$2 |
| **SOTP gesamt** | **$38** | **$54** |

*Hinweis: SOTP ist konservativ und unterschätzt möglicherweise den vollen Wert der Operating Businesses.*

## Methode 3: Distributable Earnings Multiplikator

| Szenario | DE je Aktie 2026e | Multiplikator | Implied Fair Value |
|---|---|---|---|
| Bear (18× DE, niedriger Wachstumsabschlag) | $2,70 | 18× | $48,60 |
| Base (22× DE, moderate Wachstumsprämie) | $2,75 | 22× | $60,50 |
| Bull (26× DE, volle Asset-Manager-Prämie) | $2,80 | 26× | $72,80 |

*2026e DE-Schätzung: +19–23 % YoY vs. 2025 DE $2,27/Aktie → Ø ~$2,75 je Aktie (Analystenkonsens: +19–23 %, Quellen: Globe and Mail, SearchResults)*
*Peer-Vergleich: Blackstone ~25–30×, KKR ~22–28×, Apollo ~18–22× DE-Multiple*

---

## Szenarien-Zusammenfassung & Faire Wertspanne

| Szenario | Methode | Faire Wert-Annahme |
|---|---|---|
| Bear | SOTP konservativ / 18× DE | ~$48–52 |
| Base | Plan Value-Discount 85–90 % + 22× DE | ~$58–65 |
| Bull | Vollständiger Plan Value + 26× DE | ~$72–82 |

**Modell-Faire-Wertspanne: $52 (Bär) – $80 (Bulle)**

Bei einem Kurs von $45,98 notiert BN **unterhalb** des Bären-Szenarios und ca. 33 % unter dem Plan Value – was eine klare Unterbewertung suggeriert, sofern Brookfield seinen Plan Value planmäßig weiterentwickelt.

## Sensitivitätsanalyse: Plan Value Wachstum

| Plan Value Wachstum p.a. (2026–2030) | Plan Value 2030 | Implied Fair Value 2026 (90 % Discount) |
|---|---|---|
| 10 % p.a. | ~$97 | ~$87 |
| 15 % p.a. | ~$119 | ~$107 |
| 16 % p.a. (historisch) | ~$125 | ~$113 |
| 20 % p.a. (bullisch) | ~$142 | ~$128 |

*Annahme: Markt diskontiert langfristigen Plan Value bei ~80–90 % zum jeweiligen Zeitpunkt.*

**Kernbotschaft:** Selbst bei einer Abflachung auf 10 % Plan-Value-Wachstum liegt der Barwert deutlich über dem aktuellen Kurs. Das Downside-Risiko (Bär-Szenario $52) liegt nur ~13 % über dem aktuellen Kurs – das Upside-Potenzial (Bulle $80) beträgt ~74 %.

## Risiken zur Abwärtskorrektur

- Anhaltend hohe Zinsen → Druck auf Immobilien- und Infrastrukturbewertungen
- Globale Rezession → geringere Monetarisierungen, langsameres Fundraising
- Integration BNT und Oaktree enttäuscht operativ
- Conglomerate-Discount weitet sich aus statt einzuengen
