## Strategische Positionierung

### Cloud & KI – Struktureller Wachstumstreiber

Azure ist das Rückgrat der Microsoft-Wachstumsstory. In Q3 FY2026 wuchs Azure um **39 % in konstanter Währung** YoY. Für Q4 FY2026 lautet die Guidance auf **39–40 % Azure-Wachstum** (konstante Währung). Kapazitätsengpässe begrenzen kurzfristig das erreichbare Wachstum – das Management bestätigte, dass die Nachfrage das Angebot konsistent übersteigt.

**Microsoft Cloud-Gesamtumsatz:** $54,5 Mrd. in Q3 FY2026 (+29 % YoY).

### KI-Monetarisierung

- KI-Geschäft: annualisierte Run-Rate von **$37 Mrd.** (Stand Q3 FY2026, Quelle: Alphastreet / Microsoft IR)
- Azure OpenAI Service: weiterhin führende Plattform für Enterprise-KI-Workloads
- Copilot für Microsoft 365: zahlende Basis wächst, jedoch langsamer als erwartet; US-Marktanteil unter Paid-AI-Tools sank von 18,8 % (Juli 2025) auf 11,5 % (Januar 2026)
- MAI (Microsoft AI in-house models): neue Eigenentwicklungen als OpenAI-Ergänzung und Kostendämpfer

### OpenAI-Partnerschaft – Strukturelle Veränderung

Microsoft hält eine **~27 %-Beteiligung an OpenAI** und buchte in Q2 FY2026 einen **$7,6 Mrd.-Bewertungsgewinn** aus dieser Position. Das exklusive Azure-Hosting-Arrangement wurde per Ende 2025 / Anfang 2026 neu verhandelt: andere Cloud-Anbieter können nun ebenfalls OpenAI-Modelle bereitstellen, Microsoft entfallen dafür Revenue-Share-Zahlungen an OpenAI. Effekt auf Marge langfristig positiv.

## Risikofaktoren

1. **Regulatorik:** EU und USA prüfen Microsoft-OpenAI-Beziehung auf wettbewerbsrechtliche Fragen.
2. **Capex-Risiko:** $190 Mrd. Capex in FY2026 – sollte KI-Nachfrage enttäuschen, drohen Abschreibungen auf Infrastruktur.
3. **Copilot-Adoption:** Langsame Nutzerdurchdringung in Kernprodukt Microsoft 365 gefährdet KI-Umsatzziele.
4. **Makroökonomie:** Enterprise-IT-Budgets reagieren auf Rezessionsszenarien; PC-Markt bleibt strukturell unter Druck.
